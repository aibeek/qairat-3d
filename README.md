# Qairat 3D

Интерактивная раздевалка ФК «Қайрат». Three.js / WebGL, домашняя форма 2026 и «Вратарь 1», поиск и карточки игроков, персонализация футболки. Для браузеров без WebGL предусмотрен резервный режим.

## Публикация

GitHub Actions автоматически публикует изменения из ветки `main` через GitHub Pages. Сборка и установка зависимостей не требуются.

## Источники

- 3D-основа: [Bellostas Studio](https://sdhuesca.bellostas.studio/)
- Состав и фотографии: [Премьер-лига Казахстана](https://kffleague.kz/ru/team/13)
- Образцы формы: [Football Kit Archive](https://www.footballkitarchive.com/ru/fc-kairat-komplekty-2026-t1930/)
- Текстуры формы адаптированы к 3D-моделям с помощью генерации изображений.

Неофициальный фан-проект.
